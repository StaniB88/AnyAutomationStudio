# AnyAutomation Studio

The AI engineering IDE for PLC programming with Siemens TIA Portal and CODESYS.

Downloads, updates and release notes are served from [anyautomation.ch](https://anyautomation.ch/studio). This repository no longer hosts installers.

## Download

Get the current installer at **[anyautomation.ch/download](https://anyautomation.ch/download)**. Installed versions update themselves.

If your company network only allows listed addresses, allow `anyautomation.ch` and `downloads.anyautomation.ch`.
